# Neuromorphic Encryption: Implementation

Software implementation of the neuromorphic encryption system from:

> Zhu et al., "Neuromorphic encryption: combining speckle correlography and event data for enhanced security", Advanced Photonics Nexus, 2024.  
> [DOI: 10.1117/1.APN.3.5.056002](https://doi.org/10.1117/1.APN.3.5.056002)

## How It Works

### Encryption Pipeline (Forward Model)
```
Input Image → Speckle Pattern → Event Simulation → Autocorrelation (Ciphertext)
```
1. **Speckle Generation**: Coherent scattering simulation (random phase + FFT)
2. **Event Simulation**: Simulated event camera captures pixel-level intensity changes  
3. **Autocorrelation**: Wiener-Khinchin theorem extracts correlation-domain features

### Decryption (Inverse Model)
```
Autocorrelation → U-Net (Physics-Informed) → Reconstructed Image
```
- U-Net with skip connections learns the inverse mapping
- NPCC (Negative Pearson Correlation Coefficient) loss function
- Trained on synthetic data generated by the forward model

## Quick Start

### 1. Train the Model
```bash
# With custom images
python train.py --image_dir data/custom_images --epochs 30

# With auto-generated synthetic images
python train.py --epochs 30
```

### 2. Run the Demo
```bash
# With a custom image
python demo.py --image path/to/your/image.png --model checkpoints/best_model.pth

# With a test letter
python demo.py --letter N --model checkpoints/best_model.pth
```

### 3. Use Custom Images
Place your images in `data/custom_images/` (any JPG/PNG format), then train:
```bash
python train.py --image_dir data/custom_images --epochs 50
```

## Key Parameters

| Parameter | Default | Description |
|-----------|---------|-------------|
| `key_seed` | 42 | Encryption key (random phase seed) |
| `image_size` | 128 | Image resolution (128 or 256) |
| `num_shifts` | 3 | Number of speckle motion shifts |
| `shift_pixels` | 2 | Pixels per shift |
| `event_threshold` | 0.2 | Event camera contrast threshold |

## Authentication

The system can verify if a decrypted image matches the original:
- **Correct key** → High Pearson correlation (> 0.5 = PASS)
- **Wrong key** → Low correlation (< 0.5 = FAIL)
- **Noise/cropping** → Degraded but still recognizable (robustness)
